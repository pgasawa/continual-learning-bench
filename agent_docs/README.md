# Agent Docs

Use this folder for longer agent-facing notes that do not belong in `AGENTS.md`.

Keep docs concise, source-linked, and stable. Prefer architecture, workflow, and convention notes over transient task logs. Do not store secrets, raw benchmark data, benchmark answers, run artifacts, or copied traces here.

## Local references

- `clbench_site_docs/` mirrors the public Continual Learning Bench website docs in Markdown for offline agent reference. Each file includes source URL and fetch timestamp metadata.
